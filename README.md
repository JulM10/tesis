# Plataforma para la Gestión Integral de Empleados en el Sector Hotelero
## Caso: Hotel Yacanto

### Autor
Julio Madero

# tesis
### Description
My name is Julio Madero, and this is my thesis project for the final exam of the Systems Analyst degree. It is a CRM platform designed for employee work-hour scheduling, combined with an HR system to manage employees and onboard new hires efficiently.


### Tecnologías
- Frontend: React + Vite
- Backend: Node.js + Express
- Database: MongoDB
- Version Control: GitHub

### Arquitectura
Monorepo con separación clara entre frontend y backend.

### Entornos
- Development
- Production
